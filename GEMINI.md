# GEMINI Analysis of the Online Medical Store Management System

This document provides a comprehensive analysis of the Online Medical Store Management System project, generated by Gemini.

## 🚀 Project Overview

The Online Medical Store Management System is a full-stack web application designed to manage an online medical store. It includes features for user authentication, a medicine catalog, a shopping cart, payment processing with multiple methods, prescription verification, an admin dashboard, and business reporting. The project is production-ready and built with a focus on security and scalability.

## 🛠️ Technologies Used

### Backend

- **Framework**: Express.js
- **Database**: MySQL (`mysql2`)
- **Authentication**: JWT (`jsonwebtoken`)
- **Password Hashing**: `bcryptjs`
- **File Uploads**: `multer`
- **Emailing**: `nodemailer`
- **PDF Generation**: `pdfkit`, `puppeteer`
- **Validation**: `express-validator`
- **Security**: `helmet`, `cors`, `express-rate-limit`
- **Logging**: `pino`

### Frontend

- **Framework**: React
- **Routing**: `react-router-dom`
- **HTTP Client**: `axios`
- **State Management**: React Context API, `react-query`
- **Forms**: `react-hook-form`
- **UI**: `react-toastify`, `react-quill`

## ⚙️ Setup and Installation

To set up and run the project locally, follow these steps:

1.  **Clone the repository.**
2.  **Set up the backend:**
    ```bash
    cd backend
    npm install
    npm run dev
    ```
    The backend will be running at `http://localhost:4000`.

3.  **Set up the frontend:**
    ```bash
    cd frontend
    npm install
    npm start
    ```
    The frontend will be running at `http://localhost:3000`.

## 🔩 Backend API

The backend API provides endpoints for managing users, medicines, orders, prescriptions, and more.

### API Routes

-   `POST /api/auth/register`: Register a new user.
-   `POST /api/auth/login`: Log in a user.
-   `GET /api/auth/me`: Get the current user's profile.
-   `PUT /api/auth/profile`: Update the user's profile.
-   `POST /api/prescriptions`: Upload a prescription.
-   `GET /api/prescriptions`: List user's prescriptions.
-   `POST /api/orders/checkout`: Create a new order.
-   `GET /api/orders`: List user's orders.
-   `GET /api/orders/:id`: Get order details.
-   `GET /api/medicines`: Get a list of medicines.
-   `GET /api/medicines/:id`: Get medicine details.
-   `POST /api/medicines/interactions`: Check for medicine interactions.

### Admin Routes

The admin routes are protected and require admin privileges.

-   `/api/admin/overview`: Get an overview of the system.
-   `/api/admin/medicines`: Manage medicines (CRUD).
-   `/api/admin/orders`: Manage orders.
-   `/api/admin/prescriptions`: Manage prescriptions.
-   `/api/admin/users`: Manage users.
-   `/api/admin/suppliers`: Manage suppliers.

## 🖥️ Frontend Application

The frontend is a React application that provides a user-friendly interface for interacting with the online medical store.

### Frontend Routes

-   `/`: Home page.
-   `/medicines`: Browse medicines.
-   `/medicines/:id`: View medicine details.
-   `/login`: User login.
-   `/register`: User registration.
-   `/cart`: View the shopping cart.
-   `/checkout`: Checkout page.
-   `/orders`: View user's orders.
-   `/profile`: User profile page.
-   `/admin/login`: Admin login.
-   `/admin/dashboard`: Admin dashboard.

## 🗃️ Database Schema

The database schema is designed to store information about users, medicines, orders, prescriptions, and more.

### Tables

-   `users`: Stores user information.
-   `medicines`: Stores information about medicines.
-   `prescriptions`: Stores uploaded prescriptions.
-   `orders`: Stores customer orders.
-   `order_items`: Stores the items in each order.
-   `suppliers`: Stores supplier information.
-   `payments`: Stores payment information.
-   `password_reset_tokens`: Stores tokens for password resets.
-   `medicine_interactions`: Stores information about medicine interactions.
