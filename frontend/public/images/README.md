# Product Images

Place product images in this folder or use placeholder URLs.

## Using Placeholder Images

We're using placeholder image service URLs. You can replace them with actual product images.

## Image URLs Format

For development, using placeholder images from:
- https://via.placeholder.com/400x400
- Or use actual medicine product images

## Recommended Image Sizes

- Product Card Images: 400x400px
- Product Detail Images: 600x600px
- Category Icons: 200x200px
