# Online Medical Store - Frontend

React.js frontend application for Online Medical Store Management System.

## Features

- Modern, responsive UI design
- Product browsing and search
- Shopping cart functionality
- User authentication
- Admin dashboard
- Prescription upload

## Getting Started

### Prerequisites

- Node.js (v14 or higher)
- npm or yarn

### Installation

1. Install dependencies:
```bash
npm install
```

2. Create `.env` file:
```bash
cp .env.example .env
```

3. Start development server:
```bash
npm start
```

The app will open at [http://localhost:3000](http://localhost:3000)

## Project Structure

src/
